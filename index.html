About Me

Open to opportunities

I’m a Software Quality Specialist focused on detecting anomalies and weaknesses in software, websites and games. I design, automate and execute test scenarios to ensure every release is reliable and robust.

I’ve built automation frameworks using Playwright (TypeScript) for web apps and FlaUI (C#/NUnit) for WPF desktop interfaces, both following the Page Object Model and connecting natively to Zephyr Scale for execution tracking.

I believe quality is a shared responsibility, and I focus on building maintainable, readable and reliable test suites that last.
